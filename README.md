## 🔲 QR Tool

أداة ويب متكاملة تتيح لك **إنشاء رموز QR** بتصميم احترافي أو **قراءة رموز QR** من الصور بسهولة تامة، دون الحاجة لأي تثبيت أو اشتراك.

## 🌐 جرّب الأداة الآن

**[← اضغط هنا لتجربة QR Tool](https://iofahmawi.github.io/qr-tool/)**

## ✨ المميزات

- ✏️ إنشاء رمز QR من أي نص أو رابط مع تصميم دوائر وزوايا مستديرة
- 📥 تنزيل الرمز المُنشأ كصورة PNG
- 🖼️ قراءة رموز QR من الصور عبر السحب والإفلات أو رفع الملف
- 📲 يدعم تثبيته كتطبيق على الجهاز (PWA)
- 📱 متجاوب مع جميع أحجام الشاشات
- 🌙 واجهة عربية بالكامل بخط Cairo

## 🛠️ التقنيات المستخدمة

- HTML5 + CSS3 + JavaScript (Vanilla JS)
- مكتبة [qrcode.js](https://github.com/soldair/node-qrcode) لتوليد الرموز
- مكتبة [html5-qrcode](https://github.com/mebjas/html5-qrcode) لقراءة الرموز
- خط [Cairo](https://fonts.google.com/specimen/Cairo) من Google Fonts
- Service Worker لدعم PWA

## 📊 وظائف الأداة

| الوظيفة | التفاصيل |
|---|---|
| إنشاء رمز QR | يدعم النصوص والروابط مع تصحيح أخطاء عالي المستوى (H) |
| قراءة رمز QR | يقبل صور PNG، JPG وغيرها عبر السحب أو الرفع |
| التنزيل | يُصدَر الرمز بصيغة PNG جاهزة للطباعة |
| PWA | يمكن تثبيت الأداة على شاشة الجهاز والاستخدام بدون متصفح |
